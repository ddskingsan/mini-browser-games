# 星团大作战 · 1.0.0 正式版

正式发布日期：2026-10-16。Git 标签：`sca-v1.0.0`，成品构建版本 1.0.0。基于工程 v4.0 的共享玩法，不是第三套游戏规则；独立单 HTML 历史版保持不变。

按项目所有者决定，本次作为 GitHub 正式版发布。复用 2026-10-03 的 1.0.0 候选构建，安装包与便携 ZIP 逐字节不变，没有重新编译。10 月 16 日补做后台源码 / 规则测试和静态成品复核，未重新启动 EXE、进行前台试玩或实体跨城测试。候选标签 `sca-v1.0.0-rc.1` 和历史记录保留；运行源码构建基线为 `a7fec102fbf53a0f793f0399d55c985da1225c7b`，正式标签另包含本次发行文档调整。

正式版本与测试覆盖范围分开说明：最终包前台长时间复测按用户要求停止；已有源码 4K 全屏前台五分钟平均约 67 FPS，未稳定达到 120 FPS。剩余硬件、干净机器安装和真实跨城验证仍未完成，详见 [QA](QA-1.0.0.md)。不据正式发布状态声称这些测试或 Steam 审核已经通过。

## 本次更新

- 十模式单人 / 联机继续执行同一份 `game.js`。原有 AI、随机事件、喂刺、魔王碰刺、安全区、据点、霸屏技能保留，不另写简化网络玩法。
- 修复单人暂停消耗比赛时间、R 误重开与焦点丢失后持续吐球。Esc 进入可继续的暂停菜单，重开或离开由玩家明确选择。
- 修复房主阵亡后剩余访客无法正确获胜，以及可复活模式在其他人暂时阵亡时提前结束。魔王最多 4 真人替换勇者，保留原魔王 / 魔兵槽位。
- 魔王超时、据点触发胜利与生命耗尽正确标记；访客孢子不再误用 AI 的回收 / 存续时间。
- 所有真人使用相同的模式出生基线；本地成长属性不成为联机战力优势。原模式目标人数自动补 AI，例如 4 真人大逃杀配 96 AI。
- 同源球体材质、护盾、合球冷却、孢子、镜头缩放；快照保留精确质量、富食点、刺种与护盾状态。预测也按 60Hz 共享移动规则推进。
- 服务器物理帧不再导出和重复复制整张地图；完整状态按网络发送需求惰性生成。画面与 60Hz 物理 / 20Hz 网络快照独立，不锁 60 FPS。
- 低细节状态不再强制大 AI 的昂贵发光，保留渐变球体；大量分身可只显示质量，减少重复名字遮挡。
- 玩家化首页、720p 可见开始按钮、紧凑联机大厅、十模式首次玩法提示；新增阵亡观战和可读联机结算，返回原房间后可准备再开。
- 开始 / 再开比赛时强制移除主页覆盖层；桌面性能测试改走真实大厅入口，并检查可见游戏状态与前台焦点，不再将屏幕外帧率当作玩家表现。
- 修复启动器关闭输出管道后写日志触发 EPIPE 主进程错误框；日志输出失败不再打断全屏和退出。
- 单人 / 联机共用程序生成音效；设置提供总音量、音乐和音效音量。联机完成比赛可获得本地星尘，不重复领取同一场奖励。
- 桌面存档不再依赖本地服务端口；新增有界存档、原子保存、自动备份和损坏恢复。首次读取时迁移现有浏览器进度，保留升级前外观 / 成长。
- 修复星图共鸣重载丢失、商店 Lv.20 与读取上限冲突，以及局部损坏存档字段导致整份进度回退的问题。
- 新增互联网服务器地址、连接检查、房间码 / 邀请链接和私密房间；提供 Linux + Docker + Caddy 的 HTTPS/WSS 权威服务部署方案。
- Electron 升级至 44.5.1，继续隔离网页与原生权限，保留安装目录选择、无边框全屏、可信外部链接和完整便携程序。
- 断线时清除排队的分裂 / 技能，重连不会突然执行旧动作；Forge 升级至 8.0.1，新增 Windows / Linux 规则与网络 CI。
- 服务来源白名单不再相信请求 Host 的自我声明，HTTP 与 WebSocket 都拒绝伪造来源；局域网自动发现保持不变。

## 下载与使用

安装程序 `StarClusterArena-Setup-1.0.0-win-x64.exe` 可选择位置并创建快捷方式。便携 ZIP 完整解压后双击 `StarClusterArena.exe`，不要只复制 EXE。无需额外安装 Node.js。

[正式版下载](https://github.com/wangzifan396-wzf/mini-browser-games/releases/tag/sca-v1.0.0)。本次沿用的成品 SHA-256：

```text
1E4EC4B7D06E9C10B2CA708A9CDF6CB0C4D26C2C8E9B81D9F0271DFAF597C305  StarClusterArena-Setup-1.0.0-win-x64.exe
7EE2B11FA5326B631D20B61BBC25146595AD8ED33F8A0B9E5E78C038CF743C20  StarClusterArena-Portable-1.0.0-win-x64.zip
```

局域网：在游戏里创建房间，朋友自动发现加入。异地：所有人连接同一公网 HTTPS 服务，再分享房间码 / 邀请链接；当前不附带由作者付费运行的公共服务器。

协议升级为 `sca-v1`，不与 v4.0 或更旧客户端混房。旧工程版本可从 Git 历史 / Releases 追溯，后续正式产品版本从当前主分支升级为 1.x。
